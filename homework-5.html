Numerical integration and the normal CDF

Comparing domain and value partitions, then applying numerical integration to probability.

Part 1 · Riemann and Lebesgue integration

Riemann sums partition the domain into intervals. Lebesgue integration instead groups domain points according to the values taken by the function. Both integrals agree for the bounded Riemann-integrable functions considered in this first experiment.

Domain partition: midpoint rule

Δx = (b − a)/N
xᵢ = a + (i + 1/2)Δx, for i = 0, …, N − 1
Rₙ = Σᵢ f(xᵢ)Δx

Value partition: simple-function approximation

Divide the interval from the minimum to the maximum function value into K equal bands. For each band Aⱼ in the domain, multiply its measure by the midpoint cⱼ of the value band.

Aⱼ = {x : f(x) belongs to value band j}
Lₖ = Σⱼ cⱼ λ(Aⱼ)

Here λ(Aⱼ) is computed analytically for each selected function. It is a domain length, not a count of sampled points. The numerical approximation comes from replacing the function values within each band by cⱼ.

Exact preimage measures use function-specific mathematical information. They are not available automatically for an arbitrary function.

Each method is warmed up and calibrated separately. The number of repetitions is increased to target a batch duration of at least 20 ms, up to one million integrations per batch. Five new batches are then measured. The median duration divided by the number of integrations gives the reported time per integration. Calibration and table updates are excluded from these measurements.

An asterisk marks a result whose final median batch duration was below 20 ms. Longer measurements reduce the impact of timer resolution, but browser activity and runtime optimizations can still affect the results.

Both implementations perform a number of loop iterations proportional to their resolution. However, evaluating f(x) and evaluating an analytical preimage-measure formula are different operations. Timing results depend on the function, browser and device.

Browser scheduling, timer resolution and background activity introduce noise. Small timing differences should not be interpreted as reliable performance advantages. Errors near floating-point precision should not be used to infer convergence rates.

How to interpret the results

The two methods partition different axes, so N and K control different approximation errors. Equal values of N and K do not imply equal computational work or equal accuracy.

For the value-partition method, using the lower and upper endpoints of each band produces lower and upper simple-function integrals. The exact integral lies between them. The midpoint approximation is halfway between these bounds.

Lower ≤ ∫f(x) dx ≤ Upper
Upper − Lower = (b − a)Δy
|Lₖ − ∫f(x) dx| ≤ (b − a)Δy/2

These bounds rely on exact preimage measures. They would require additional error control if those measures were estimated from a finite sample.

A very small error at one resolution does not establish a general convergence rate. Symmetry, cancellation and alignment with a discontinuity can make particular cases unusually accurate.

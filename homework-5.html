Numerical integration and the normal CDF

Comparing domain and value partitions, then applying numerical integration to probability.

Part 1 · Riemann and Lebesgue integration

Riemann sums partition the domain into intervals. Lebesgue integration instead groups domain points according to the values taken by the function. Both integrals agree for the bounded Riemann-integrable functions considered in this first experiment.

Domain partition: midpoint rule

Δx = (b − a)/N
xᵢ = a + (i + 1/2)Δx, for i = 0, …, N − 1
Rₙ = Σᵢ f(xᵢ)Δx

Value partition: simple-function approximation

Divide the interval from the minimum to the maximum function value into K equal bands. For each band Aⱼ in the domain, multiply its measure by the midpoint cⱼ of the value band.

Aⱼ = {x : f(x) belongs to value band j}
Lₖ = Σⱼ cⱼ λ(Aⱼ)

Here λ(Aⱼ) is computed analytically for each selected function. It is a domain length, not a count of sampled points. The numerical approximation comes from replacing the function values within each band by cⱼ.

Exact preimage measures use function-specific mathematical information. They are not available automatically for an arbitrary function.

Browser scheduling, timer resolution and background activity introduce noise. Small timing differences should not be interpreted as reliable performance advantages. Errors near floating-point precision should not be used to infer convergence rates.

An integrable singularity: 1/√x

The function 1/√x is unbounded near zero. Its integral on (0, 1] exists as an improper Riemann integral and as a Lebesgue integral, with value 2. It is not a proper Riemann integral of a bounded function on [0, 1].

∫₀¹ x⁻¹ᐟ² dx = lim ε→0⁺ ∫ε¹ x⁻¹ᐟ² dx = lim ε→0⁺ 2(1 − √ε) = 2

The numerical experiment currently uses ε = 0.0001, so both methods integrate over [0.0001, 1]. The reference value displayed in the tables is therefore 1.98, not 2.

Truncated integral: ∫ε¹ x⁻¹ᐟ² dx = 2(1 − √ε) = 1.98
Omitted area: ∫₀ε x⁻¹ᐟ² dx = 2√ε = 0.02

Increasing N or K improves the numerical approximation of the truncated integral. It does not remove the omitted area while ε remains fixed. Convergence to the full integral also requires controlling the truncation error.

If A approximates the truncated integral, then:

|A − 2| ≤ |A − 1.98| + 0.02

For this particular function, the omitted area is known exactly. Adding 0.02 to A gives a corrected estimate of the full integral, whose error equals the numerical error on the truncated interval. Such an exact correction is not generally available.

How to interpret the results

The two methods partition different axes, so N and K control different approximation errors. Equal values of N and K do not imply equal computational work or equal accuracy.

For the value-partition method, using the lower and upper endpoints of each band produces lower and upper simple-function integrals. The exact integral lies between them. The midpoint approximation is halfway between these bounds.

Lower ≤ ∫f(x) dx ≤ Upper
Upper − Lower = (b − a)Δy
|Lₖ − ∫f(x) dx| ≤ (b − a)Δy/2

These bounds rely on exact preimage measures. They would require additional error control if those measures were estimated from a finite sample.

A very small error at one resolution does not establish a general convergence rate. Symmetry, cancellation and alignment with a discontinuity can make particular cases unusually accurate.

Pathological examples and the limits of sampling

Dirichlet's function

D(x) = 1 if x is rational
D(x) = 0 if x is irrational
Domain: [0, 1]

Every nonempty interval contains both rational and irrational numbers. Therefore, every lower Darboux sum is 0 and every upper Darboux sum is 1. The function is not Riemann-integrable.

The rational numbers form a countable set of Lebesgue measure zero. Consequently, D is zero almost everywhere and its Lebesgue integral is 0. “Almost everywhere” means outside a set of measure zero.

A Riemann sum using only rational sample points is always 1. One using only irrational sample points is always 0. Refining the partition does not resolve this disagreement.

Thomae's function

T(x) = 1/q if x = p/q in lowest terms, with q > 0
T(x) = 0 if x is irrational
Domain: [0, 1]

Thomae's function is continuous at irrational points and discontinuous at rational points. Its discontinuity set has measure zero, so the bounded function is Riemann-integrable. Its Riemann and Lebesgue integrals are both 0.

For any positive threshold, only finitely many rational points in [0, 1] have function values above that threshold. These finitely many tall peaks can be enclosed in intervals of arbitrarily small total length. All remaining values are small. This explains why the integral is zero despite the dense set of rational points.

This experiment evaluates known rational points. It does not test whether arbitrary real numbers are rational. Finite JavaScript floating-point numbers are rational; they cannot directly represent arbitrary irrational sample points.

For Dirichlet's function, the rational midpoint sums remain 1, despite the Lebesgue integral being 0. For Thomae's function, the sums approach 0, but need not decrease at every tested resolution. One observed sequence of sums alone is not a proof of Riemann integrability.

Countability and measure, rather than numerical sampling alone, determine the Lebesgue integrals in these examples. A finite sample cannot generally detect the distinction between a dense measure-zero set and its complement.

Part 2 · Numerical computation of the normal CDF

For a standard normal random variable Z, the cumulative distribution function Φ(z) gives the probability P(Z ≤ z). The density is:

φ(t) = exp(−t²/2)/√(2π)
Φ(z) = ∫₋∞ᶻ φ(t) dt

Symmetry allows us to integrate over a finite interval:

Φ(z) = 1/2 + ∫₀ᶻ φ(t) dt, for z ≥ 0
Φ(z) = 1/2 − ∫₀⁻ᶻ φ(t) dt, for z < 0

This experiment compares the composite trapezoidal rule with composite Simpson's rule. Both use N equal subintervals and N + 1 density evaluations when z is nonzero. Simpson's rule requires an even N.

Public-Key Cryptography

Private key → public key through elliptic-curve scalar multiplication.

Assigned 8 October 2016

From private key to public key

We use the toy curve y² ≡ x³ + 7 (mod 17), with base point G = (1, 5). The public key Q = kG is computed by repeated point addition.

Educational example only. This small curve is not secure. Ethereum uses secp256k1, with much larger parameters.

Explore integers from 1 to 1000. Since G has order 9, the results repeat every 9 values. The distinct nonzero private keys for this toy subgroup are 1 to 8.

Homework 02

Encryption and Cryptanalysis

Comparing an elliptic-curve encryption scheme with the Caesar cipher, then investigating their weaknesses.

Aim of the experiments

We encrypt and decrypt the same message using two schemes: the Caesar cipher and a hybrid scheme based on secp256k1, with an intentionally restricted recipient private-key space.

We then investigate two attacks: statistical recovery of the Caesar shift and exhaustive search of the restricted elliptic-curve private-key space.

1. The Caesar cipher

Each letter is replaced by the letter a fixed number of positions further along the alphabet. We encode A,…,Z as 0,…,25.

Encryption: c = (p + s) mod 26.
Decryption: p = (c − s) mod 26.

Here p represents a plaintext letter, c a ciphertext letter, and s the secret shift. Encryption and decryption use the same key, so this is a symmetric cipher.

ASCII letters are converted to uppercase. Spaces, digits and ASCII punctuation are preserved. Accented letters are not supported in this experiment. Both encryption schemes will use the same normalized text.

Key space and statistical properties

        
          

            There are 26 possible shifts, including zero, which leaves
            the message unchanged. The same plaintext and key always
            produce the same ciphertext.
          

        
          

            Every occurrence of a letter is replaced by the same letter.
            Letter frequencies are therefore shifted, not hidden.
            Repeated-letter patterns remain visible. In this implementation,
            spaces and punctuation also reveal part of the message structure.
          

        
          

            Correct decryption does not imply security.
            An attacker can examine all 26 possible shifts.
            Language statistics can help identify the most plausible one.
